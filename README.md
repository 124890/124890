## Selected work

### [Satellite imagery pipeline for oil-storage research](https://github.com/124890/Floating-Lid-Tank-Depth)

A Python command-line prototype combining mapped tank discovery, satellite imagery providers, OpenCV image analysis, JSON diagnostics and inspection overlays. Provider access is separated from the estimator, with seven unit tests covering synthetic images and mocked provider responses.

**Start here:** [Quick start and architecture](https://github.com/124890/Floating-Lid-Tank-Depth#quick-start) · [Implementation](https://github.com/124890/Floating-Lid-Tank-Depth/blob/main/satellite_fill.py) · [Tests](https://github.com/124890/Floating-Lid-Tank-Depth/blob/main/test_satellite_fill.py)

**Status:** research prototype. The fill output is an uncalibrated image heuristic; accuracy against real tank levels has not been established.

### [Concrete compressive-strength modelling](https://github.com/124890/Comp-Challenge---2023-4)

Collaborative coursework comparing eight regression methods in scikit-learn, with preprocessing, hyperparameter search, model diagnostics and interactive feature-removal analysis.

**Team:** Douglas Penning, Roman Ogorodnov, Manish Saharan and Ryan Hutchings.  
**Status:** educational analysis. The README explains evaluation-split reuse and the improvements needed for an independent benchmark.

### [Biopolymer films for sustainable packaging](https://github.com/124890/IOP_v1)

Research poster examining how fruit purées affect starch–gelatine film properties. The repository contains the LaTeX source and figures for communicating optical, wetting and mechanical results. This research won first prize at the Institute of Physics Sustainable Materials Symposium.

**Authors:** Douglas Penning, Alvin Zhu, Gabriel Yang and Manjula Silva.  
**Focus:** experimental analysis and scientific communication.
